# Аналитика записей с сайта «Культура» (через Google-Форму)

Считает **намерение записаться с сайта**: открытие формы записи к мастеру (во
фрейме) и клики «Записаться» на профиль DIKIDI. Работает **без скриптов и без
доступа к вашему Google-аккаунту** — только Google-Форма и связанная таблица.

> Это не число совершённых записей — их знает только DIKIDI (смотрите там по
> метке `source=website_kultura`). Здесь — интерес/клики с сайта.

## 1. Создать форму (один раз, ~5 минут)

1. Откройте [forms.new](https://forms.new) — новая Google-Форма.
2. Настройки (шестерёнка) → убедитесь, что **НЕ** включены «Собирать адреса
   эл. почты» и «Ограничить: 1 ответ» (форма должна принимать анонимные ответы).
3. Добавьте **5 вопросов типа «Текст (строка)»** ровно в таком порядке и с
   такими названиями (названия любые, но порядок важен):
   1. `type`
   2. `master`
   3. `where`
   4. `page`
   5. `ts`
   Обязательными их делать не нужно.

## 2. Узнать адрес отправки и id полей

1. Справа вверху — **⋮ → Получить предварительно заполненную ссылку**.
2. Впишите в каждое поле что-нибудь (например, `1`,`2`,`3`,`4`,`5`) →
   **Получить ссылку** → **Копировать ссылку**.
3. В скопированной ссылке будут пары вида `entry.1234567=1`. Выпишите номера
   `entry.XXXX` по порядку — это id полей `type, master, where, page, ts`.
4. Адрес отправки = ссылка на форму, где `viewform` заменён на `formResponse`:
   `https://docs.google.com/forms/d/e/ВАШ_ID/formResponse`.

## 3. Прописать это в сайт

В [`../js/config.js`](../js/config.js):

```js
window.KULTURA_FORM = {
  action: "https://docs.google.com/forms/d/e/ВАШ_ID/formResponse",
  fields: {
    type:   "entry.1111111111",
    master: "entry.2222222222",
    where:  "entry.3333333333",
    page:   "entry.4444444444",
    ts:     "entry.5555555555"
  }
};
```

Закоммитьте и запушьте — сайт начнёт слать события в форму, а Google — в
связанную таблицу (вкладка «Ответы» в форме → значок таблицы).

## 4. Где смотреть цифры

### Вариант А — прямо в таблице (просто, приватно)

В таблице ответов колонки: `A` — отметка времени, `B` — type, `C` — master,
`D` — where, `E` — page, `F` — ts. На отдельной вкладке «Сводка» можно
посчитать формулами (замените имя листа `Ответы на форму (1)` на своё):

```
Всего событий:        =СЧЁТЗ('Ответы на форму (1)'!B2:B)
Открыли форму:        =СЧЁТЕСЛИ('Ответы на форму (1)'!B2:B; "booking_open")
Клик на профиль:      =СЧЁТЕСЛИ('Ответы на форму (1)'!B2:B; "profile_click")
Данил:                =СЧЁТЕСЛИ('Ответы на форму (1)'!C2:C; "Гуляев Данил")
Андрей:               =СЧЁТЕСЛИ('Ответы на форму (1)'!C2:C; "Терёшкин Андрей")
```

Разбивку по мастерам/дням удобно смотреть через **Вставка → Сводная таблица**
(без формул).

### Вариант Б — страница admin.html на сайте (графики)

1. В таблице ответов: **Файл → Поделиться → Опубликовать в интернете**.
2. Выберите **вкладку ответов** и формат **CSV** → «Опубликовать».
3. Скопируйте ссылку (вида `…/pub?output=csv`).
4. Откройте `https://<ваш-сайт>/admin.html`, вставьте эту ссылку — увидите
   сводку с графиками. Ссылка хранится только в вашем браузере (в репозиторий
   попадать не обязана). Публикуются только счётчики кликов, без личных данных.

## Ограничения

- Считаются клики/намерения, а не подтверждённые записи.
- Форма принимает анонимные ответы, поэтому теоретически счётчик можно
  накрутить. Для барбершопа некритично.
- Опубликованный CSV обновляется с задержкой в несколько минут.
