# Аналитика записей с сайта «Культура»

Считает **намерение записаться с сайта**: открытие формы записи к мастеру (во
фрейме) и клики «Записаться» на профиль DIKIDI. Данные пишутся в вашу
Google-таблицу; сводка видна на защищённой ключом странице `/admin.html`.

> Это не число совершённых записей — их знает только DIKIDI (смотрите там по
> метке `source=website_kultura`). Здесь — интерес/клики с сайта.

## Настройка (один раз, ~5 минут)

1. Создайте новую **Google-таблицу** (sheets.new).
2. **Расширения → Apps Script**. Удалите пустой `myFunction`, вставьте
   содержимое [`Code.gs`](./Code.gs).
3. В строке `var SECRET = '...'` замените значение на свой секретный ключ
   (любая длинная строка). Он же вводится в админке. Сохраните (Ctrl/Cmd+S).
4. **Развернуть → Новое развёртывание**:
   - тип — **Веб-приложение**;
   - «Выполнять от имени» — **Я**;
   - «У кого есть доступ» — **Все** (Anyone).
   - Нажмите «Развернуть», разрешите доступ к таблице.
5. Скопируйте **URL веб-приложения** (заканчивается на `/exec`).
6. Вставьте этот URL в [`../js/config.js`](../js/config.js):
   ```js
   window.KULTURA_TRACK_URL = "https://script.google.com/macros/s/…/exec";
   ```
   Закоммитьте и запушьте — сайт начнёт слать события.
7. Откройте `https://<ваш-сайт>/admin.html`, введите тот же секретный ключ —
   увидите сводку.

## Что видно в админке

- всего событий и разбивка: открытия формы к мастеру vs клики на профиль;
- по мастерам (Данил / Андрей);
- по дням (график за 14 дней);
- последние события списком.

## Обновить код бэкенда

После правок в `Code.gs` в Apps Script снова **Развернуть → Управление
развёртываниями → (карандаш) → Новая версия**. URL `/exec` не меняется.

## Ограничения

- Считаются клики/намерения, а не подтверждённые записи.
- Публичный эндпоинт: технически кто-то может слать фейковые события
  (счётчик можно накрутить). Для барбершопа это некритично; при желании
  позже вынесем на Cloudflare Worker с проверкой.
- Секретный ключ защищает только **чтение** сводки в админке.
